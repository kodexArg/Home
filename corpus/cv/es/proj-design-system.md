El SyV Design System (Subordinación y Valor) es el sistema de diseño oficial de las plataformas kodexArg. Define tokens de diseño, la paleta presentation orange, estética de consola oscura, mecánica de input estilo Pip-Boy y reglas de componentes accesibles. Es lo que le da su aspecto a este sitio.
