Engram is an agent-agnostic persistent memory system for AI coding agents, written in Go as a high-performance binary using SQLite with FTS5 full-text search, and exposing an MCP server, an HTTP API, a CLI and an interactive TUI. It addresses the context-window problem: long-term memory outside the model.
