Gabriel built an IoT advertising system for TV screens on a Raspberry Pi fleet with a central content repository, for the Casino de Mendoza. He later repurposed that same infrastructure into a real-time thermal map of the casino floor, with DHT11 and DHT22 sensors, a Django backend and ChartJS visualisation. It ran for years. The repository for this project is private.
