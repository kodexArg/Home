Eurotrip 2026 is a personal travel companion built with Angular 21 and running entirely on Cloudflare — Pages, D1 (distributed SQLite) and R2 for media — with interactive maps, budget calculation and schedule management. It is live and the code is open. It is his reference project for full-Cloudflare work.
