### 3.1 North-star use cases 1. **Invisible background memory:** User installs via Homebrew or engram setup; agent saves bugfixes and decisions proactively; next session the agent searches memory before repeating mistakes (docs/intended-usage.md golden rule: infrastructure you forget exists). 2. **Compaction survival:** Claude Code / OpenCode plugins inject Memory Protocol skill and post-compaction hooks; agent re-saves session summary and recovers context after context window reset. 3. **Cross-machine continuity:** Developer runs engram sync, commits .engram/ chunk, pulls on laptop, engram sync --import — memories follow the git repo. 4. **Operator browse:** Human runs engram tui or engram search "auth middleware" without an agent, inspecting what the agent remembered. 5. **Obsidian cognitive map (beta):** Export to vault; open Graph View to see session hubs and topic_key clusters as a navigable knowledge graph.
