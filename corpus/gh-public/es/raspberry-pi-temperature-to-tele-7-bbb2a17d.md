### 3.2 Non-goals - No web UI, REST API, or mobile app — Telegram is the sole remote interface. - No authentication on bot commands (any Telegram user who can message the bot receives responses). - No automated alerting or scheduled Telegram pushes — all interaction is pull/on-demand. - No multi-Pi fleet management or centralized dashboard. - README references an older clone path (raspberry-temp-humi) and repo naming; the current GitHub name is raspberry-pi-temperature-to-telegram.
