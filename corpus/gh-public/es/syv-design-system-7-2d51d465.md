### 3.2 Non-goals - Not a publishable npm/Dart package with semver releases in this repo (it is a consultation/library repo). - Not a complete Flutter UI kit here — only the Dart token file; widgets are in syv-pj-flutter. - No documented automated build/regeneration script (manual process described in INDEX.md §6). - No CI/CD, no HTTP API, no database — pure static assets and documentation. - Original *Diseño Naranja* and external reference bundles are gitignored and out of tree.
