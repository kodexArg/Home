### 3.2 Non-goals - Not the QA execution environment—no agents, scripts, skills, or cloned repos live here (those belong in kodexArg/QA). - Not a build pipeline—no bundler, package manager, or CI config in-tree; reports are hand-or-agent-compiled static HTML. - Not a markdown or JSON findings API—companion .md files may be written upstream but are deliberately untracked here. - Not access-controlled or redacted publishing—visibility is public for all committed HTML. - Not a live monitoring or regression system—each file is a point-in-time audit snapshot.
