## cowsay

> **Problem thesis (required):** kodexArg/cowsay exists because AI coding agents routinely improvise cowsay-style ASCII art by hand, and the results are visually inconsistent, misaligned, and non-reproducible. The repository ships a **deterministic, stdlib-only Python renderer** plus an **Agent Skills** instruction pack so agents pipe every cowsay-mode reply through and display only its stdout. The renderer is law: same text, same flags, same width environment → same bytes every time.
