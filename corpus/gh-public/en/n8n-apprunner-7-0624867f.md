### 3.2 Non-goals - Shipping custom n8n nodes, community packages, or workflow JSON exports in this repo. - Defining CI/CD beyond App Runner's native GitHub integration (no .github/workflows present). - Container-based deployment (no Dockerfile). - Enabling n8n task runners / queue workers in this configuration (N8N_RUNNERS_ENABLED=false). - Telemetry (N8N_DIAGNOSTICS_ENABLED=false).
