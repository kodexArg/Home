# syv-image-generation > **Problem thesis (required):** This repository is the **visual portrait factory** for the *Subordinación y Valor* (SyV) universe. It exists because lore-rich character data lives in sibling repos ( sheets, canon) but **images must be produced locally on a GPU via ComfyUI**, with every generation documented, ranked, and fed back into prompt calibration. Without this repo, portrait work would be ad-hoc: prompts would not be reproducible, good/bad combos would not accumulate, workflows would not be versioned, and agents would invent palette or faction details outside the SSOT. The central pain is **bridging structured narrative character data → deterministic natural-language prompts → ComfyUI jobs → human-curated visual memory** on a machine with tight VRAM (8 GB class GPU).
