### 3.2 Non-goals - No system package installation (apt install cowsay is explicitly forbidden in agent rules). - No freehand ASCII by the agent when the skill is active. - No balloon logic inside .cow files or cow geometry inside dialog.py. - No SKILL.md at repo root — skill lives under skills/cowsay/ per package convention. - No HTTP server, database, or cloud deployment surface.
