# qa-reports > **Problem thesis (required):** The kodexArg QA workspace runs ten parallel audit agents against cloned repositories and live deployments, producing dense findings across security, accessibility, performance, SEO, code quality, functionality, dependencies, compliance, operations, and framework best practices. Those deliverables must survive outside the private sandbox: clients, operators, and future agents need a stable, browsable archive of finished audit reports with uniform scoring, severity taxonomy, and launch verdicts. This repository is that public sink—HTML-only, auto-published from the QA workspace, with a canonical template and an internal workflow reference page—so audit knowledge is portable without exposing the testing sandbox or cloned target repos.
