### 3.2 Non-goals - No wake word, no chit-chat personality, no always-on listening without explicit hard switch (per PRD.md §5). - No cloud APIs, telemetry, or API keys in the product loop. - No free-form shell generation from LLM output — whitelist router only. - No GNOME/X11; Hyprland is the sole product surface. - kodexBot never starts or selects the LLM server; it only consumes an OpenAI-compatible HTTP API on loopback.
