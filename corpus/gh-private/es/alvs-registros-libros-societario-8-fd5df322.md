Micro for safe navigation intent matching; assistant app models support AI chat sessions and generated documents (lawyer/accountant personas). Users without a granted Django Group land on the **lobby** (/) per adr-20-authorization-lobby. Authenticated editors navigate entity directories, book/folio workflows, shareholder registries, compliance dashboards, litigation dockets, chat UI, profile theming, and admin surfaces (audit logs, module permissions, tax-obligation catalog). Theme tokens are CSS custom properties; users tune appearance on /profile. Growth is **by addition**: new capabilities become new domain endpoints and Astro pages; the harness (PRD, ADRs, API SSOT, hooks, skills) stays fixed.
