# syv-game-system > **Problem thesis (required):** This repository is the **platform-agnostic design vault** for *Subordinación y Valor* (SyV), a simultaneous-turn (WEGO) tactical wargame set in a militarized alternate Patagonia. It exists so that rules, mechanics, lore, and abstract data models live in one Obsidian-structured knowledge base that any future implementation — physical tabletop, PC, or mobile — can consume without rewriting design from scratch. The vault deliberately separates human-readable reglamento from machine-oriented JSON schemas, documents a deterministic combat resolver ("Fricción") distinct from a planned Gemini-powered narrative layer, and enforces agent editing conventions so AI-assisted design work stays consistent and non-contradictory.
