### P5 — AI agent coherence during feature development - **Who hurts:** AI coding agents dispatched to extend Django projects without architectural guardrails — they introduce JS frameworks, pip commands, scattered templates, or custom User models. - **Pain today:** Agents lack a constitution, spec workflow, and slash commands; each session reinvents patterns and violates project constraints. - **How this repo answers:** Ships **Spec Kit integration**: .specify/memory/00-template-setup/constitution.md (12 non-negotiable constraints), .claude/commands/speckit-*.md slash commands (specify → clarify → plan → tasks → analyze → implement), and docs/spec-kit.md workflow guide. Agents must read the constitution first and follow uv-only, no-comments (use Loguru), minimal try/except, and living documentation principles. - **Out of scope:** The Spec Kit CLI itself (external tool); agent skills stored outside this repo.
