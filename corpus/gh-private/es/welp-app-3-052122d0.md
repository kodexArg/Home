### P2 — Multi-tenant organizational scoping without a separate database per unit - **Who hurts:** Staff who must only see tickets for their UDN/sector; security reviewers ensuring cross-tenant isolation. - **Pain today:** Shared tools often leak data when queries fetch by primary key alone; role matrices sprawl across views. - **How this repo answers:** Roles links users to (UDN, Sector, role_type) with permissions derived from PAYFLOW_ROLE_PERMISSIONS on save. welp_payflow/utils.py centralizes authorization (superuser → staff → role checks). Ticket.objects.get_queryset(user) scopes list/detail queries. Templates hide actions via server-side {% if %} checks — no client-side permission logic. - **Out of scope:** Perfect isolation today — documented **IDOR debt** remains on htmx_single_ticket and AttachmentView (see docs/devops/security.md); authenticated users can still read some tickets/attachments by ID until fixed.
