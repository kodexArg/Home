# PyCreadorPJ > **Problem thesis (required):** Tabletop GMs running the Spanish **Rápido y Fácil** system for the **Subordinación y Valor** post-apocalyptic module need fast, rule-faithful random characters (PNJs) with attributes, skills, inventory, initiative, defense, and culturally appropriate names. This private Flask web app automates that workflow from static JSON/CSV game data, renders printable character cards in the browser, and optionally surfaces bundled adventure lore from .
