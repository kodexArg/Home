# ComfyUI > **Problem thesis (required):** ComfyUI exists so anyone working with Stable Diffusion can design, run, and automate complex diffusion pipelines through a visual node graph that mirrors how SD actually works — loading checkpoints, conditioning, sampling, VAE decode, post-processing — while a built-in async server exposes the same execution engine to scripts and external clients. It prioritizes modularity, partial re-execution of only changed subgraphs, broad model-format support, and offline operation over a simplified one-click consumer UI.
