### 3.2 Non-goals - Hosting HTTP traffic (no WSGI server binary, no nginx, no application routes). - Modern Python or Django versions (frozen at 3.7 / Django 3.0.3). - Minimal/slim images — the repo is large (full conda prefix with tk, openssl, scipy stack, etc.). - Secret or environment configuration management (no .env templates in repo). - Agent scaffolding or hidden docs vaults (.claude/ and .docs/ absent).
