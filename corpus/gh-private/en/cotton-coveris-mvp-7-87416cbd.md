### 3.2 Non-goals - SSR/SSG for the main app (CSR only; rejected stack per README and ADR-002-b). - External state libraries on frontend (NgRx, TanStack Query)—Signals, httpResource(), Signal Forms only. - Persisting computed hours balance in the database (computed on the fly per ADR-011). - Automatic ADR adoption by agents—human-in-the-loop required (AGENTS.md). - Pushing to prod branch by agents (owner-only, direct AWS production deploy).
