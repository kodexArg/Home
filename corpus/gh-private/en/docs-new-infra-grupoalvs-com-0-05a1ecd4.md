# ALVS New-Infra AWS Platform Docs > **Problem thesis (required):** This repository is the living specification and publication pipeline for ALVS's greenfield AWS platform — a deliberately simple, cost-conscious, convention-driven stack for workloads. It exists so architects, operators, and AI agents share one evolving truth about networking, security, compute, databases, Cognito identity, CI/CD, and per-project bootstrap — while the actual infrastructure is provisioned separately and legacy systems remain untouched.
