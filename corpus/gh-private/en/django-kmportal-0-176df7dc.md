# KM 1151 Enterprise Portal > **Problem thesis (required):** This repository is a Django web application for **KM 1151**, a fuel-station enterprise serving B2B fleet customers in Argentina. It digitizes the workflow from **fuel order creation** (by authenticated company users via social login) through **QR-based handoff** to **pump operators** who record refueling on a staff intranet, plus a parallel **ExtraCash** (cash transfer) module. The README explicitly marks the project as **work in progress and not production-ready**, but substantial modules (orders, vehicles, company, staff refueling, i18n, CI/CD hooks) are already implemented.
