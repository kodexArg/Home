# DjangoConda > **Problem thesis (required):** This repository is **not a Django application** — it is a **complete, pre-built Conda environment prefix** checked into git. It exists to give kodexArg operators and developers a frozen, copy-paste Python 3.7 runtime already containing Django 3, PostgreSQL adapter (psycopg2), WSGI-capable framework dependencies (via Django + asgiref), and a broad set of Django ecosystem packages (tables, Bootstrap, REST framework, compressor, analytics). The pain it attacks is environment drift: instead of running and dozens of commands on each server or laptop, one shallow clone yields an executable tree under , , and ready for activation or path-based use.
